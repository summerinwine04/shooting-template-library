# AI拍摄 · try-on 视觉模板库（本地版）

一个**纯本地、零依赖服务**的模板库。按 **类目（男装 / 女装 / 运动 / 童装）** 顶层组织，
类目下沿用 PRD 的标签体系（图组级 4 维 + 图片级 10 维），用于日常 AI 拍摄的**模板筛选与取材**。

打开方式：双击 **`index.html`**，浏览器即开，不需要装任何服务器或数据库。

---

## 目录结构

```
视觉模板库/
├── index.html              ← 双击打开，浏览/筛选/预览/复制路径
├── 元数据录入模板.xlsx       ← 录入图组与图片标签（含下拉、示例行）
├── README.md
├── data/
│   ├── 标签字典.json         ← 类目 + 全部标签维度与枚举（可改）
│   ├── templates-data.js    ← 自动生成的清单，网页读取（勿手改）
│   └── templates-data.json  ← 同上，JSON 版，方便给别的程序/Agent 用
├── templates/               ← 图片实际存放处
│   ├── 男装/<图组名>/xxx.jpg
│   ├── 女装/<图组名>/xxx.jpg
│   ├── 运动/...
│   └── 童装/...
└── 工具/
    └── rebuild_manifest.py  ← 扫描图片 + 读 Excel → 重建清单
```

> **童装已导入 22 个真实图组 / 92 张实拍图**（来自 桌面/童装模板 + Downloads/模板库，已逐张 AI 打标，含亚洲/欧美模特）。
> 男装/女装/运动 暂为占位示例（各 2 组），可随时替换成真实素材。

> **按类目独立标签**：每个类目有自己的标签维度。**童装已确认**（图组级 8 维含年龄段/性别/出镜形式，图片级 11 维含表情/展示角度），存于 `data/标签字典-分类目.json`。男装/女装/运动暂用「通用」schema，待逐类目确认后替换。网页里切到某个类目，左侧就会显示该类目专属的筛选维度。

## 日常使用三步走

**1. 放图** —— 把图片拷进对应类目文件夹，按图组分子文件夹：
```
templates/女装/清新自然·户外·咖啡馆/01_全身_正面.jpg
templates/女装/清新自然·户外·咖啡馆/02_上半身_微侧.jpg
```

**2. 填标签** —— 打开 `元数据录入模板.xlsx`（已按类目分表）：
- **童装**：填【童装图组】+【童装图片】两张表，列就是童装确认好的维度（年龄段/性别/出镜形式/表情/展示角度等）。
- **男装/女装/运动**：暂填【通用图组】+【通用图片】，等各自标签体系确认后会拆出专属表。
- 图片表用 **图组ID** 关联到图组表；`图片文件` 列填**相对路径**（从库根目录算起，同上例）。
- 大部分字段有下拉；图组级多选字段用顿号 `、` 分隔，如 `童趣可爱、活泼开朗`。
- 效果数据（生产/CTR/SA 等）由下游回流，留空会显示「暂无」。

**3. 重建清单** —— 双击或命令行运行：
```bash
python3 工具/rebuild_manifest.py
```
它会扫描 `templates/` 的图片、读取 Excel 标签，生成最新的 `data/templates-data.js`。
然后**刷新 `index.html`** 就能看到新内容。

> 没填 Excel 的图也不会丢——会照样进库，标签显示「待补全」。

## 在网页上直接「新增图组 · 上传图片组」（推荐）

双击 index.html（file://）只能浏览，不能上传落盘。要在页面里上传新图组，需要启动本地服务：

**最简单：双击 `启动.bat`**（Windows）。它会自动装依赖、起服务、打开浏览器。首次会装 openpyxl，稍等几秒。窗口保持开着＝服务在运行，关掉窗口即停止。

> 手动方式（Mac / 没有 bat）：命令行进入本目录，运行 `python3 工具/启动模板库.py`（先 `pip install openpyxl`）。

启动后浏览器会打开 `http://127.0.0.1:8765/index.html`。**必须用这个网址的页面**（不是双击 html）：

1. 点右上角 **＋ 新增图组**。
2. 选类目 → 选好**图组级标签**（决定自动命名：人种·年龄·场景·风格）。
3. 拖入图片，给**每张**打全图片级标签（红框=未选，必须打全才能提交；可用「把第①张的标签套用到全部」加速）。
4. 点**提交入库** → 自动存图到 `templates/`、写入 Excel、重建清单、刷新页面，新图组立即出现。

> 上传走本地回环（127.0.0.1），不联网、不外传。提交时若 Excel 正开着会提示先关闭。

## 网页能做什么

- **顶部类目切换**：全部 / 男装 / 女装 / 运动 / 童装（带数量）。
- **左侧筛选**：搜索范围（仅图组 / 仅图片 / 混合）+ **按当前类目显示该类目专属维度**多选（如童装是 8 维图组级 + 11 维图片级）。选「全部」时只按类目+关键词浏览。
- **两种视图**：聚合（图组大卡）/ 平铺（图组缩略 或 图片网格）。
- **排序**：首图优先 / CTR / 生产次数 / 名称。
- **图组详情**：封面 + 模特场景 + 图组标签 + 效果数据 + 组内图片网格。
- **大图预览**：完整图片级标签 + 单图效果数据 + 左右键翻图 + **一键复制路径**（可直接当 AI 拍摄 reference 喂给生产）。
- **首图高亮**：主图首图 / 种草首图 的图片带 ⭐ 角标并排序靠前。

## 想定义其他类目 / 改标签？

编辑 `data/标签字典-分类目.json`：
- `schemas.<类目>` 下填 `group_level` / `image_level`，每个维度含 `label`（中文名）、`multi`（是否多选）、`values`（枚举）。
- 把该类目的 `status` 改为 `confirmed`；未定义的类目会自动回退到 `schemas.通用`。

改完重新运行 `工具/rebuild_manifest.py` 即可生效。Excel 的下拉是生成时写死的，
新增/改维度后需要把对应类目的 Excel 表也重做一份（可让我帮你重新生成）。

## 给 Agent / 程序对接

`data/templates-data.json` 是结构化全量清单，字段与上传 PRD 的数据模型一致
（group / image、group-level / image-level tags、metrics）。下游素材 Agent 可直接读它做按标签取材，
未来要接成线上 API（`POST /query` 等）也可平滑迁移。
